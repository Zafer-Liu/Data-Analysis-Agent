# 前端请求与状态加固

本轮保留现有 Vue island、侧栏、面板和主题，只收敛知识库、本体、团队的请求与状态。

## 公共请求契约

`createApiClient` 支持 HTTP 与业务 envelope 错误、稳定 code/status/requestId、正文超时、AbortSignal、会话过期以及 FormData/二进制响应。写请求不自动重试；网络失败或超时提示先刷新核对服务器结果，不能假定操作没有发生。

`createRequestOwner` 按 session/domain/选择代次管理读取。过期读取不覆盖新状态；取消读取和切换会话会作废 UI 所有权。写入锁一直保留到原操作结束，即使期间 reset 也不能重复提交副作用。

本体服务器确认成功但浏览器副本保存失败时，只重试本地保存。团队及 Workflow 多阶段操作在阶段之间检查范围，避免旧运行详情或 Artifact 补读覆盖新选择。

## 用户状态

知识列表、表单、上传、本体确认和团队面板具备加载、取消、空结果、错误及重试状态。新增提示使用双语 catalog；表单标签关联控件，错误/加载具备 ARIA 状态。团队显示取消请求与实际退出确认，并显示结构化复核的证据缺口。

## 验证

新增或扩展 44 项针对性 Node 回归，全部使用合成 fetch/DOM/存储错误；共享前端测试还覆盖构建资源与入口约束。真实浏览器检查桌面中文浅色、手机英文深色、表单与团队空态，确认无横向溢出及控制台错误。缺失服务器模型配置时，不调用真实推理。

最后的测试、构建、detector 与浏览器记录见 [optimization-validation.md](optimization-validation.md)。
