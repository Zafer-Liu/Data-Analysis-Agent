# 本地模型与服务

设置 → 本地服务用于保存多个具名连接。连接方式（HTTP / Docker）决定地址如何填写，服务协议决定可以执行的动作；容器本身不等于某种模型协议。

打开页面只读取配置。保存不会启动服务、下载模型、安装依赖或拉取镜像；“保存并测试”会在保存后发送一次协议检查请求。

| 服务协议 | 检查方式 | 可用动作 |
|---|---|---|
| 自定义 HTTP | GET 用户配置的健康检查路径 | 手动发送已配置路径的 GET / JSON POST，查看响应 |
| OpenAI 兼容 | GET `/v1/models`（基础地址已有 `/v1` 时不重复添加） | 发现模型，选取真实模型 ID 加入现有 LLM 列表 |
| TimesFM | 验证 `/health` 的服务标识、模型与 ready 状态 | 明确点击“用于预测”，交给既有 `run_analysis` 分析链路 |

## 添加 HTTP 或 Docker 服务

1. 先启动自己的服务，确认它提供 HTTP(S) 接口。
2. 点击“添加服务”，填写名称、服务协议、连接方式与基础地址，例如 `http://127.0.0.1:8000`。地址不能包含密钥。
3. 自定义 HTTP 服务需填写健康检查路径与调用路径，例如 `/health`、`/ocr`。没有 `/health` 时使用该服务实际提供的 GET 路径。
4. 需要认证时在“认证与超时”填写 Bearer 密钥。密钥保存在系统凭据库，配置文件只保存引用；更换服务地址后不会沿用原地址的密钥。
5. 保存并测试；自定义 HTTP 可在编辑区域手动“发送请求”。响应按文本显示，最多接收 1 MiB，页面最多展示 12000 字符。

Docker 服务可使用宿主机映射地址。智析也在容器内时，`127.0.0.1` 指智析容器自身，需使用同网络服务名或可达的 Docker 主机地址，例如 `http://ocr:8000` 或 Docker Desktop 的 `http://host.docker.internal:8000`。此页面不会访问 Docker 引擎、枚举容器或执行 Docker 命令。

本机与 Docker 服务名可使用 HTTP；其他远程地址要求 HTTPS。请求路径必须属于已保存的服务，拒绝跨站重定向，避免将 Bearer 密钥发送到其他端点。

## 用于聊天或分析

OpenAI 兼容服务可以指向已启动的 Ollama、vLLM 等兼容接口；实际支持以模型列表检查为准。点击“加入 LLM 列表”后，在 LLM 设置或模型选择器中选用该模型。此操作注册提供商配置，不会自动切换当前会话模型，也不会运行推理。

TimesFM 连接测试通过后，点击“用于预测”。多个预测连接可分别保存，但同一时间仅使用一个当前预测服务。编辑其地址、协议、认证或超时会停用当前预测配置，修改完成后需重新选择。移除当前预测连接也会停用对应预测配置，均不停止已经运行的模型服务或容器。

已有 TimesFM 配置会继续显示，无需重新添加。页面下方“下载或使用已有模型”提供 TimesFM 的“下载模型”和“使用已有模型”两种方式；Python、端口等位于高级设置中，已启动的模型可试运行或停止，参见 [TimesFM 说明](../timesfm/README.md)。其他模型环境由用户独立管理。

**连接可访问不等于模型推理正确，也不等于 Agent 已理解任意 HTTP 协议。** 自定义 HTTP 当前支持连接管理和手动请求调试；自动将数据送入 OCR、检索或其他专业模型，仍需增加对应工具适配器。TimesFM 已有预测适配器；OpenAI 兼容协议复用现有 LLM 提供商能力。

连接检测结果记录时间，页面显示“上次可访问 / 上次连接失败”，不会将历史状态冒充持续在线监控。托管云网页不开放共享主机的本地连接配置；请使用桌面版或本地部署。

## 停止模型并释放显存

支持控制的服务会在连接行中显示“停止模型”。点击并确认后结束后台模型，保留模型文件与连接配置；成功后显示“已停止”，同时停用对应的当前预测连接。停止正在处理请求的模型可能中断预测。

应用托管的 TimesFM 使用实例身份验证与关闭接口。已有独立 Windows 服务可由可信的本地安装流程调用 `infrastructure.local_service_control.register_stop_script(cfg, script)` 登记停止脚本；脚本路径及 SHA-256 保存在运行配置中，浏览器只提交服务 ID，不能提交或执行任意命令。脚本修改后须重新登记，服务地址、协议或连接方式改变后旧控制不再生效；脚本成功退出还需确认端口已关闭，才能报告停止。

本机既有 TimesFM 停止脚本已接入当前验收连接，脚本核对 PID、命令行与创建时间，并结束 venv 启动器及实际模型子进程。其他未登记的 HTTP / Docker 服务仍由其所属程序或容器平台管理，不会按端口强制结束未知进程。手动重新启动该服务后，点击“测试连接”可重新允许停止操作。

当前功能没有 GPU 租赁、用量结算或支付。TimesFM 权重许可仍限非商业、非生产研究。
